Docente e ingeniera orientada a la formación práctica en tecnologías modernas de desarrollo, integración y procesamiento de datos.

En este curso acompañará a los estudiantes en el aprendizaje progresivo de Apache Kafka, desde sus conceptos fundamentales hasta la construcción de soluciones basadas en eventos y procesamiento de datos en tiempo real.

📚 Sobre el curso

Este repositorio contiene el material académico, laboratorios, ejemplos, ejercicios y proyectos correspondientes al curso de Apache Kafka.

Durante el curso se estudiarán los fundamentos de los sistemas distribuidos orientados a eventos y se desarrollarán aplicaciones prácticas utilizando el ecosistema de Kafka.

## 📖 Recursos

### 📚 Documentación oficial

- 📨 [Apache Kafka Documentation](https://kafka.apache.org/documentation/)
  - Documentación general, conceptos, arquitectura, configuración y guías de Apache Kafka.

- 🔧 [Apache Kafka API Documentation](https://kafka.apache.org/documentation/#api)
  - Referencia de las APIs de Kafka para Producers, Consumers, Admin, Streams y Connect.

- 🌊 [Kafka Streams Documentation](https://kafka.apache.org/documentation/streams/)
  - Documentación oficial para construir aplicaciones de procesamiento de streams con Kafka.

- 🐳 [Docker Documentation](https://docs.docker.com/)
  - Documentación oficial de Docker, contenedores, Docker Compose, CLI y herramientas del ecosistema.


Los enlaces específicos y materiales complementarios podrán agregarse progresivamente durante el curso.
